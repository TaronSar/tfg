The ...Embention whl file
is a modification of the original Air Transport Canada tool installable from cam_track_gen-0.1.0-py3-none-any.whl and found in https://github.com/nrc-cnrc/Canadian-Airspace-Models/tree/main/Track%20Generation%20Tool
The modifications are limited to track_generation_tool.py and are only useful for the Embention internal use.
